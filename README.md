# 🤖 FAQ LUX Chatbot

FAQ LUX Chatbot is an interactive Question-Answer chatbot built using **Python, TF-IDF Vectorization, and Gradio**.  
It allows users to ask questions related to services/products, and it provides the most relevant answer from a FAQ dataset.

---

## 🚀 Features

- Answers user queries based on FAQ dataset
- Uses **TF-IDF Vectorizer** for text similarity
- Finds best match using **Cosine Similarity**
- User-friendly interface powered by **Gradio**
- Returns fallback message when confidence is low

---

## 🛠️ Technologies Used

- Python  
- Gradio  
- Scikit-learn  
- TF-IDF Vectorizer  
- Cosine Similarity  
- JSON FAQ Dataset
